# PayiCharge Website

A simple responsive advertising website for PayiCharge.

## Pages
- Home
- Locations — Gqeberha, Eastern Cape
- Gallery — concept visuals
- About Us

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Put these files in the PayiCharge repository.
2. In GitHub, open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select the main branch and `/ (root)`.
5. Save and wait for GitHub Pages to publish.

## Content basis
The website uses the supplied PayiCharge business proposal concepts: a 10-bay secure charging locker, R20 charging token, venue-managed model, proposed 15% venue commission, and Gqeberha as the current location.

The Gallery uses original CSS/SVG-style concept illustrations rather than copying third-party product photographs.
